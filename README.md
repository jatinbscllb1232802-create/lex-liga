# Lex Liga Futsal

Temporary live scoring & fixtures website for the college Futsal tournament **Lex Liga**.

- Free hosting (GitHub Pages)
- Live scores, fixtures, standings, top scorers
- Protected Admin panel with easy +1/–1 controls
- Modern dark sports design, mobile-first
