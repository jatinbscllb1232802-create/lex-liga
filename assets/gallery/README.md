# Photo Wall gallery

Upload matchday photos here (`.jpg`, `.png`, `.webp`).

They appear automatically on **gallery.html** within about a minute (or after refresh).

**How to upload during the event**
1. Open this folder on GitHub → **Add file** → **Upload files**
2. Drop photos → Commit
3. Open the Photo Wall page and refresh

Tip: name files with time, e.g. `2026-09-16-final-1.jpg`
